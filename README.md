# Egg Hunt!

### CMSC 137: Data Communications and Networking Project (2nd Sem 2025-2026)


## Game Overview
In this game, players inhabit a poultry farm where hens have colorful nests. 
However, during a festival, the eggs were scattered around the farm when children played with them. 
Now, players must search the farm and the town to collect as many eggs as possible and return each one to its matching nest. 
For every round, the player with the most collected eggs wins. 
It’s an easter egg hunt in a farm setting!


## How to Install/Run
1. Clone the repository to your local machine.

```
git clone <repository-url>
```

2. Navigate to the project directory.

```
cd egg-game
```
3. Download the jar file `egg.jar`. This can be found on the root directory of the project.

4. Run the jar file using the command line.

```
java -jar egg.jar
```
Note: Make sure that you have Java installed on your machine to run the game. You can download it from [here](https://www.java.com/en/download/).

## How to Play

1. Upon launching the game, you will be greeted by the Main Menu section where you can explore game instructions, and customize your avatar. You can also start a game room or join an existing one.

2. Once you start a gain room, you will be taken to the lobby where you can wait for other players to join. 

3. Once all the players have joined, you can press the "Start Game" button to begin the game.

4. Every player must collect and deliver the eggs to their same-colored nests. The player with the most collected eggs wins the game. The game will end after a certain time limit (120 seconds) or when all eggs have been collected.

5. During the game, players can also chat with each other.
